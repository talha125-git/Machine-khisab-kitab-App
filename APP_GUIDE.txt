2. DATA PARITY & BACKEND CONNECTION
--------------------------------------------------------------------------------
How the app connects to the same data as the web:
  1. Backend Server:
     The web app's Express backend runs on port 5000:
     D:\Apps\Projects\Machine war data\backend\server.js
     Connected to MongoDB Atlas:
     mongodb+srv://abutalhaa844_db_user:...@cluster0.hj1igey.mongodb.net/machine_war_data

  2. Authentication Parity:
     • POST /api/auth/login
     • POST /api/auth/signup
     When you log in with your existing account (e.g. abutalhaa844@gmail.com),
     the app receives the exact same user ID and credentials.

  3. Kitab Data Parity:
     • GET    /api/kitabs      (requires 'x-user-id' header)
     • GET    /api/kitabs/:id  (requires 'x-user-id' header)
     • POST   /api/kitabs      (creates new 15-day cycle)
     • PUT    /api/kitabs/:id  (updates day records and summary)
     • DELETE /api/kitabs/:id  (deletes kitab)

  4. Local Session Persistence:
     The app uses SharedPreferences (analogous to the web app's localStorage)
     to store the user session ('khisab_user') and custom server URL settings.
